## 阅读与导出

打开章节查看原文、改写结果或图文内容，使用目录与章节切换继续阅读。阅读位置会保存。未改写章节在合并输出中使用原文，避免只导出部分章节造成内容缺失。

导出格式在项目配置中选择：TXT 输出纯文本；EPUB 可包含已插入正文的图片。章节总结可另行导出为 Markdown。导出前检查章节顺序、改写结果及插图位置。

## 第一次使用听书：先下载模型

**1.0.0 起，Windows 与 Android 安装包都不附带语音模型。** 软件保留语音引擎；没有模型时，第一次点击听书会打开“音色与模型”，由用户选择“下载并安装”。普通阅读、总结、改写和配图不依赖语音模型。

| 模型 | 选择参考 |
| --- | --- |
| 轻量中文女声（AISHELL3） | 适合先体验，下载及安装空间较小 |
| Kokoro 中文女声 · INT8 | 提供更多音色，资源占用介于轻量和标准版之间 |
| Kokoro 中文女声 · 标准 | 与 INT8 提供同组音色，可自行试听比较 |

实际下载大小、安装预留空间、版本与许可在模型卡片显示。下载后校验并安装；网络失败可重试，下载中可取消，已有模型可检查修复。当前正在使用的模型需要先切换后才能删除。下载源的网络可用性会影响速度。

![软件内下载语音模型](../images/voice-models.png)

模型保存在应用持久数据目录，软件升级继续复用，不需要每个版本重新下载。模型安装成功后在本地合成语音，听书本身无需调用文本模型接口。

## 音色与播放

已安装模型可试听、选择音色，并使用搜索、收藏及备注管理声音。试听会暂停听书并保留原位置。播放器支持语速、目录、上一章与下一章、从指定位置开始、跟读定位及进度恢复。

提前合成默认 3 段，可在界面提供的档位中选择；增加段数会增加缓存。重启后可继续听书，不会自动发声。安卓后台播放依赖系统允许的服务和通知状态。

![听书界面](../images/listening.png)

公开截图来自安卓模拟器的非语音验收构建，仅展示界面；实际语音下载、校验与播放在安装后的 Windows 正式包验证。手机端语音和后台播放由用户在真实设备体验与验收。
