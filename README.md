# RENovel releases

This repository distributes RENovel Windows x64 installers, Android arm64 APKs,
update manifests, checksums, release notes and third-party notices.

Download the latest version from **Releases**. Subsequent versions can be installed
from **设置 → 应用更新** inside RENovel. Android asks for installation permission
and system confirmation. Windows users should install the setup package once.

Updates preserve local projects, settings, reading progress and installed voice
models. Update packages exclude voice model weights. GitHub access is required.

No user manuscripts, local databases, credentials or private source code are
stored in this distribution repository.
